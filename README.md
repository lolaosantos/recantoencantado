# Site Mamãe Decora e Recanto Encantado

## O que tem na pasta
- `index.html`: a página
- `assets/`: fotos e logos
- `sitemap.xml` e `robots.txt`: ajudam o Google a encontrar a página

## Domínio
O endereço do site já está configurado como `https://recantoencantado.com.br/` no `index.html`, no `sitemap.xml` e no `robots.txt`. O arquivo `CNAME` diz ao GitHub Pages qual domínio usar.

## Usar domínio próprio (.com.br)
1. Registrei o domínio no Registro.br.
2. Em Settings > Pages > Custom domain, digite o domínio e salve. Marque "Enforce HTTPS" quando liberar.
3. No painel de DNS do Registro.br, aponte o domínio para o GitHub conforme a documentação atual: https://docs.github.com/pages (seção "Managing a custom domain").

## Depois de no ar
1. Google Search Console (search.google.com/search-console): adicione o site, confirme que é seu e envie o `sitemap.xml`.
2. Google Meu Negócio: crie o perfil da chácara (e da decoração, se atender com endereço ou área de atendimento) com o link do site.
3. Coloque o link na bio dos dois Instagrams e no WhatsApp Business.
